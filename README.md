# starship

My personal [Starship](https://starship.rs) prompt configuration.

## Install

Clone the repo, move only the config file into `~/.config/`, and remove the leftover folder:

```sh
git clone https://github.com/Eugene-U/starship.git
mv starship/starship.toml ~/.config/starship.toml
rm -rf starship
```

Requires a [Nerd Font](https://www.nerdfonts.com/) for the icons (glyphs) to render correctly.
